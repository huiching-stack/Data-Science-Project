# House Sales in King County, USA (Data Analytics Final Project)

This repository contains the final project for the IBM Data Analyst / Machine Learning professional certificate coursework, focusing on predicting housing prices in King County (including Seattle) using Python[cite: 3].

## 📋 Project Workflow
1. **Importing Datasets:** Loaded housing transaction data and inspected structures.
2. **Data Wrangling:** Dropped redundant columns (`id`, `Unnamed: 0`), identified missing values, and imputed missing entries for bedrooms and bathrooms using column means[cite: 3].
3. **Exploratory Data Analysis (EDA):** Used Seaborn and Matplotlib to analyze floor distributions, waterfront price outliers, and feature correlations with price[cite: 3].
4. **Model Development:** Built Single and Multiple Linear Regression models to predict housing prices[cite: 3].
5. **Model Evaluation & Refinement:** Implemented pipelines containing standard scalers, polynomial features, and Ridge regression models, evaluating performance via $R^2$ scores[cite: 3].

## 🛠️ Technologies Used
* **Language:** Python[cite: 3]
* **Libraries:** Pandas, NumPy, Scikit-Learn, Seaborn, Matplotlib[cite: 3]
